# Milady's Knight — Controls & Key Binds

## 6. Key binds :

Pas de support manette. Pas de support souris, tout se fait au clavier.

| **Right Arrow** | aller vers la droite                                                                   |     |
| --------------- | -------------------------------------------------------------------------------------- | --- |
| **Left Arrow**  | aller vers la gauche                                                                   |     |
| **E**           | interagir / confirmer                                                                  |     |
| **F (hold)**    | attaquer / tirer                                                                       |     |
| **G**           | attaque d'atterissage (impact)                                                         |     |
| **R (hold)**    | attaque spéciale (Dragon Slayer uniquement)                                            |     |
| **Space**       | sauter / double jump / skip dialog                                                     |     |
| **A**           | alterner/ sélectionner slot équipement 1 & 2                                           |     |
| **Up Arrow**    | monter                                                                                 |     |
| **Down Arrow**  | descendre                                                                              |     |
| **ESC**         | annuler/fermer (fenêtre de contexte, chest), revenir en arrière OU mettre jeu en pause |     |
